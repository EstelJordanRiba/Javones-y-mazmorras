# Javones-y-mazmorras
Proyecto en Java que simula personajes de un juego de mazmorras utilizando programación orientada a objetos.

Clases implementadas

Personaje: clase base de los personajes.

Guerrero: puede proteger a un compañero.

Mago: puede lanzar hechizos usando maná.

Ladron: puede hacerse invisible y robar.

Inventario: almacena el equipamiento del personaje.

Equipamiento: representa los objetos equipables.

Main: ejecuta la simulación del programa.
